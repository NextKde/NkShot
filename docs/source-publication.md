# Initial source publication

This is a source prototype, not a compiled or runtime-tested release. Fourteen source-level checks passed before publication; they do not validate capture, recording, OCR, translation, rendering, or install behavior.

The repository begins with a source snapshot, not a transfer of upstream Git history. Spectacle baseline: v6.8.3, commit `5f5af4b83f5329396117af03234c012464404257`. Kos.Ui comes from NextKde/nextkdeAppDemo commit `608847c9231121b888f11c4e5f84850ac95deda4`; its 29 QSB shader resources were verified byte-for-byte against that public revision. Original copyright and license notices remain in place.
